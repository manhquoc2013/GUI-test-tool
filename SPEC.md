# Technical Specification: AI Assistant Chat Management, Copy, Revert/Undo & Token Optimization

## 1. Objective
Enhance the dedicated AI Assistant screen (`AiAssistantPageController`) and AI generation workflow with:
1. **Copy & Undo Message Support**:
   - Provide a 1-click **Copy** button on every chat bubble (user & assistant) to copy content to clipboard.
   - Provide an **Undo / Hoàn tác** button on chat messages:
     - Revert the chat state (removes the message and its AI response).
     - Roll back any test cases, preview scripts, and assertions generated by that message.
     - If the user already applied the generated cases into the target Suite on disk, rollback the Suite state (restoring `suite.json` and case scripts to their pre-applied snapshot).
2. **Persistent Chat History Management**:
   - Save and restore chat history per Suite / Group in persistent JSON storage (`.ai_chat.json`).
   - Automatically switch and load chat history when the user selects different Groups / Suites.
   - Support clearing history with confirmation, tracking timestamps, and preserving context across app restarts.
3. **Advanced Token Optimization**:
   - **Sliding Window Context**: Keep the most recent N turns (default 6) for context while omitting older redundant turns from model API calls.
   - **Context Token Estimation & Live UI Indicator**: Accurate heuristic estimation (Vietnamese + English + code) showing current prompt and context tokens (e.g., `Tokens: ~420 / 4,000`).
   - **Context Auto-Summarization**: When historical conversation exceeds token budget, compress older turns into a compact context summary prompt.
   - **Attachment Compression**: Remove redundant whitespace, blank lines, and boilerplate from attached files/documents before sending to OpenAI to minimize token consumption.

## 2. Architecture & Components

### 2.1 Models (`com.studio.model.ai`)
- `AiChatMessage`:
  - `id`: Unique UUID
  - `role`: "user" | "assistant" | "system"
  - `content`: Message text
  - `timestamp`: Creation time
  - `estimatedTokens`: Token count
  - `attachedFileNames`: List of attached filenames
  - `previewCasesSnapshotJson`: JSON snapshot of generated preview cases
  - `suiteSnapshotJson`: JSON snapshot of target suite and case script files before changes were applied
  - `suiteSnapshotDir`: Path to target suite directory for rollback
- `AiChatSession`:
  - `suiteKey`: Target group/suite identifier
  - `messages`: List of `AiChatMessage`
  - `summary`: Compressed summary of older pruned messages (for context preservation)

### 2.2 Token Optimizer Service (`com.studio.service.AiTokenOptimizer`)
- `estimateTokens(String text)`: Estimates token count (~3.8 characters per token for English, ~1.8 for Vietnamese/multilingual, weighted code tokens).
- `estimateMessage(AiChatMessage msg)`: Estimates tokens for a message.
- `compressText(String text)`: Cleans redundant whitespace, collapses blank lines, truncates repetitive logs.
- `buildOptimizedMessages(AiConfig config, List<AiChatMessage> history, String currentPrompt, List<ParsedDocument> attachments, String contextInfo)`:
  - Generates optimized message list within token limits.
  - Applies sliding window (last 6 turns).
  - Prepends compressed historical summary if older messages were evicted.
  - Compresses attached document contents.

### 2.3 Chat History & Snapshot Store (`com.studio.store.AiChatHistoryStore`)
- File path: `suiteDir/.ai_chat.json` (or workspace-level if no suite selected).
- Methods:
  - `loadSession(Path suiteDir)`
  - `saveSession(Path suiteDir, AiChatSession session)`
  - `clearSession(Path suiteDir)`
  - `createSuiteSnapshot(Path suiteDir)`: Captures `suite.json` and all `.java` files in the suite.
  - `rollbackSuiteSnapshot(Path suiteDir, String snapshotJson)`: Restores `suite.json` and `.java` files, removing newly added files.

### 2.4 UI & Controller (`AiAssistantPageController.java` & `ai_assistant_page.fxml`)
- Chat bubble styling with action bar:
  - Header: Role, Time, Token count badge.
  - Content label.
  - Action row (shown neatly on bubble or hover):
    - `Copy`: Copies text to `Clipboard.getSystemClipboard()`, triggers success toast.
    - `Undo`: Prompts confirmation if suite changes occurred, removes turn, restores preview state, reverts suite files if applied, and re-saves history.
- Top bar enhancements:
  - Token counter badge: `fx:id="tokenUsageBadge"` showing `~Tokens: 350 / 4,000`.
- Dynamic Suite switching:
  - Listens to `targetSuiteCombo` changes, automatically saves current suite chat history, and loads the new suite's chat history.

## 3. Testing & Verification
- Unit test for `AiTokenOptimizer`: token estimation accuracy, sliding window filtering, document text compression.
- Unit test for `AiChatHistoryStore`: session serialization, suite snapshot capture, and rollback of modified/created test files.
- Unit test for `AiAssistantPageController` logic & message model state transitions.
- Offline compilation (`mvn test-compile -o`) and full suite run (`mvn test -o`).
